# Task report format

Copy this block at the end of every implementation task. It is the format required by [AGENTS.md](https://github.com/hilather/go-lab-ldap-mcp/blob/main/AGENTS.md).

```text
Task: T-XXX
Result: complete | partial | blocked
Files changed: ...
Tests run: ...
Acceptance criteria: pass/fail by item
Security notes: ...
Follow-up tasks: ...
```

Do not claim completion when integration or acceptance tests were skipped.
